# Support

- Download the current stable build from [GitHub Releases](https://github.com/ixiehao/ShotTessera/releases/latest).
- For a reproducible bug or a feature idea, use the [issue forms](https://github.com/ixiehao/ShotTessera/issues/new/choose).
- Before reporting playback trouble, check whether the source video plays in a
  macOS system media player; supported containers can still contain a codec
  unavailable on a particular Mac.
