# Product naming

Use one product name per document language so release notes, README files, and
installation material stay consistent:

| Document language | Product name |
| --- | --- |
| English | `ShotTessera（视频一键截屏拼图）` |
| 简体中文 | `视频一键截屏拼图` |
| 日本語 | `動画ワンクリック・スクリーンショットモンタージュ` |

`ShotTessera` remains the repository, bundle identifier, Homebrew cask, and
GitHub project identifier. The macOS application file is intentionally named
`视频一键截屏拼图.app`; installation instructions may use that exact filename
when describing a Finder action.
